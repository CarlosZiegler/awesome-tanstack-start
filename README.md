# 🧱 Awesome TanStack Start

A curated list of projects, templates, tools, and resources built with [TanStack Start](https://tanstack.com/start/latest).

TanStack Start is a modern full-stack web application starter built by the creators of TanStack (React Query, Router, Table, etc.). It provides a batteries-included approach to building scalable, performant web applications using a modular and type-safe architecture.

Inspired by [awesome-shadcn-ui](https://github.com/birobirobiro/awesome-shadcn-ui).

## 🤝 Contributing

Have a project, template, or tool built with TanStack Start? Feel free to open a PR!

Please follow this structure:

```md
| [ProjectName](link) | Short description | Stack: Next.js, TanStack Router, etc. | [Repo](link) | [Demo](link) |
```

Make sure your entry is:

- Publicly accessible
- Actively maintained (or at least working)
- Relevant to the TanStack Start ecosystem
